# HumanProof Records

このフォルダは、正本から意図的に省いた「検討の過程」を保存する。

## なぜ分けるか

- 正本は短く、現在の結論だけを読める状態に保つ
- 判断台帳は採否と理由を追跡する
- Recordsは、元回答・依頼・統合作業・未解決事項を失わないようにする

## Authority

Recordsは証跡であって正本ではない。矛盾時は次を優先する。

1. `00_MASTER/HumanProof_MASTER.md`
2. `00_MASTER/DECISIONS.md`
3. `04_DEVELOPMENT/MVP_Scope.md`
4. `04_DEVELOPMENT/Requirements.md`
5. Records

原回答に含まれる統計、URL、市場規模、競合不在、法規制等は、別途一次情報で確認するまで未検証として扱う。
