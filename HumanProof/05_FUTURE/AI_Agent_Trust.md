# AI Agent Trust — Future

## Vision

AI Agentについて、正体を丸ごと明かすのではなく、次の権限Proofを示す。

```text
Agent A
✓ Authorized by Company X
✓ Can schedule meetings
✓ Can purchase up to ¥10,000
× Cannot sign contracts
Valid until ...
Revocable ...
Audience ...
```

## Link to current MVP

Human向けMVPと共通する原理:

- Trusted Issuer / Authorizer
- minimum disclosure
- audience binding
- explicit scope
- expiry
- revocation
- verification and audit

## Status

**Futureとして採用、MVP実装は却下。** 市場時期、標準、購買主体、責任分界は未検証。
