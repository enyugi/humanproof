# IAMme / HumanProof サイトデザイン参照

## デザインの目的

プロモーションLPを豪華に見せることではなく、次の3つを視覚だけで分ける。

1. IAMme — 長期プロダクト／構想
2. HumanProof — AI HACK 2026で動くPoC
3. NIGHT SCREEN — PoCを体験する架空サービス

## ファーストビュー

- 左または上側にHumanProof PoCの印刷物風ポスター
- 右または下側に一言価値
- `デモを試す` はページ内アンカーではなく `/demo` への遷移
- ヘッダーの主語はIAMme
- `HumanProof / AI HACK 2026 PoC` は実装断面として表示

## コンポーネントの見た目

- 面の区切りは影でなく1px罫線
- ボタンは直角、黒または深緑
- ステータスのみ小さなpillを許可
- 証明は深緑のスタンプ／枠として表現
- 身分証や個人情報は薄灰のフォーム・カード形状で表現し、具体的な実在人物データは使わない
- 仕組み図はPCで横3段、モバイルで縦積み

## 日本語組版

- `line-break: strict`
- 見出しは `text-wrap: balance` を使用してよいが、本文には使用しない
- `<br>` は意味のある文節境界だけに使う
- 狭いカラムへ長文を入れず、本文幅を確保する
- モバイルでは補足説明を短くし、操作ボタンを先に見せる
